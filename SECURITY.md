# Security policy

## Supported versions

The `main` branch is the active development line. Releases and tags may be supported only as stated in their release notes.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue, pull request, or chat message. Use GitHub's private vulnerability reporting option from the repository's **Security** tab when it is available.

If private reporting is unavailable, contact the repository administrators through [t.me/pagepet_reader](https://t.me/pagepet_reader) and start the message with **security**. Include a short description, affected revision, reproduction steps, and the smallest useful log or proof. Do not send passwords, tokens, private keys, or other unrelated personal data.

We will acknowledge reports when possible, investigate in private, and coordinate a public fix or advisory after the issue is understood. Please allow time for investigation before public disclosure.
